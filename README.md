# 属灵日记 PWA v0.3

## 部署
将 ZIP 解压后的全部文件上传到支持 HTTPS 的静态网站根目录，例如 GitHub Pages / Cloudflare Pages。

## iPhone 安装
1. 用 Safari 打开部署后的网址。
2. 点 Safari 的“分享”。
3. 选择“添加到主屏幕”。
4. 从桌面打开，即以独立 PWA 运行。

## 数据
- 当前数据保存在浏览器 localStorage。
- “更多 → 导出 JSON”可完整备份。
- “更多 → 导入 JSON”可恢复。
- 删除浏览器网站数据、删除某些 PWA 数据或更换设备前，请先导出备份。

## v0.1 功能
- 今日属灵日记
- 祷告事项及状态
- 感恩快速记录
- 经文收藏与标签
- 时间线 / 日历回顾
- 搜索
- 中文 / English / 跟随系统
- 浅色 / 深色 / 跟随系统
- JSON 导入导出
- PWA 离线缓存


## v0.2 新增：拍照识别经文
- 经文收藏页 → “📷 拍照识别”
- iPhone 可直接调用相机，也可以从相册选择图片
- 浏览器内使用 Tesseract.js OCR 中文 + 英文
- 自动尝试识别常见中文/英文书卷名与章节范围
- OCR 后必须人工确认，可修改错字、删除页码/标题等
- 可保存到经文收藏
- 可一键加入今天的日记
- 原始照片仅用于当前识别与预览，默认不永久保存
- 首次 OCR 需要联网加载 OCR 引擎/语言数据；之后浏览器通常会缓存


## v0.3
